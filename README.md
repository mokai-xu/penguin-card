# Holiday Card Generator

A pixel art style holiday card generator built with React, TypeScript, and Konva.js.

## Features

- **Templates**: Choose from multiple card templates with different border styles
- **Stickers**: Drag and drop emoji stickers onto your card
- **Text Customization**: Add "To:", "From:", and custom messages
- **Message Generator**: Generate random holiday messages with one click
- **Interactive Editing**: Drag, resize, and delete elements on the canvas
- **Export**: Save your card as a PNG image

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Tech Stack

- React 18
- TypeScript
- Konva.js / react-konva
- Vite

## Design

- Minimalistic pixel art style
- Color palette: #386641, #6a994e, #a7c957, #f2e8cf, #bc4749, #73ba9b
- Fonts: Press Start 2P (titles), Roboto Mono (body)
